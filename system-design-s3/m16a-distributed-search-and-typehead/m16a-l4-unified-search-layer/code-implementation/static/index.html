System Operation & Telemetry Guide Under the Hood
1. How to Interact with the Surface
• Typeahead Autocomplete: Type any characters in the search box. The client queries the in-memory Trie (from Lab 2) in 0.016ms using precomputed node Top-K heaps.
• Execute Full Search: Type a query and click "Execute Full Search" to route to primary Elasticsearch (from Lab 3) on port 9200 with Porter stemming and BM25 scoring.
• Compare Both Engines: Click "Compare Both Engines" to run the query simultaneously against Elasticsearch and the in-memory fallback index and inspect the side-by-side performance tradeoff.
2. Telemetry Metrics Explained
• Keystrokes: Total physical key events registered by the input listener.
• Emitted Calls: Actual HTTP network requests dispatched to /suggest.
• Suppressed: Requests cancelled by the 200ms debounce timer or blocked by prefix gating.
• QPS Saved: Percentage of backend query volume saved (Suppressed / (Emitted + Suppressed)), showing 75%–85% traffic reduction.
3. Waterfall Status Flags Explained
• 200 OK: Request succeeded and returned from server within SLA.
• GATED (< 2 chars): Keystroke prefix shorter than 2 characters; suppressed at client / dropped at gateway to avoid single-letter cache thrashing.
• CANCELLED (Debounced): Active 200ms debounce timer aborted because another key was pressed.
• PRIMARY (ES): Full-text search executed against primary Elasticsearch cluster.
• DEGRADED (RAM): Full-text search diverted to the zero-IPC in-memory inverted index due to circuit breaker trip or SLA breach.
4. Chaos Administration (One-Liners)
• Trip Circuit Breaker: Forces the circuit to OPEN, immediately quarantining Elasticsearch and demonstrating that searches gracefully degrade to in-memory RAM in 0.02ms without failing.
• Reset Circuit Breaker: Forces the circuit back to CLOSED, immediately resuming normal high-recall primary routing to Elasticsearch.
